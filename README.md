# Spider Dance

Аркадная игра на **C++** и **SFML**: птица бегает по трём паутинам, уклоняется от пауков и опускающихся волн.

![[Screenshot.png]]
## Скачать

Готовая сборка для Windows: раздел [Releases](../../releases/latest). Распакуйте архив и запустите `SpiderDance.exe`.

Если при запуске появляется ошибка про `VCRUNTIME140.dll` или `MSVCP140.dll`, установите [Microsoft Visual C++ Redistributable](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist).

Музыка необязательна: игра запускается и без неё. Чтобы включить звук, положите файл `music.ogg` рядом с `.exe`.

## Управление

| Клавиша | Действие                     |
| ------- | ---------------------------- |
| `←` `→` | Двигаться влево / вправо     |
| `↑` `↓` | Перейти на линию выше / ниже |

## Игровые механики

- **Три линии-паутины.** Игрок переключается между ними и бегает вдоль них.
- **Пауки** выходят по расписанию из файла и ползут по своей линии. Касание наносит урон.
- **Волны** опускаются сверху и накрывают линии от верхней до своего уровня. Если в момент пика игрок находится на накрытой линии, он получает урон.
- **Здоровье:** 2 единицы. После удара 3 секунды неуязвимости (птица мигает).
- **Регенерация.** При 1 HP птица краснеет и через 10 секунд здоровье восстанавливается.
- **Смерть:** при 0 HP окно закрывается.

## Расписания спавна

Уровнем управляют два текстовых файла рядом с `.exe`. Перекомпилировать ничего не нужно.

**`spiderList.txt`**: по записи на строку: `время линия направление скорость`

| Поле        | Допустимые значения           |
| ----------- | ----------------------------- |
| время       | секунды от старта, ≥ 0        |
| линия       | `0`, `1`, `2` (сверху вниз)   |
| направление | `1` (вправо) или `-1` (влево) |
| скорость    | 0–1000 пикселей в секунду     |

Пример: `2.5 1 -1 150`: на 2,5 секунде по средней линии справа налево со скоростью 150.

**`waveList.txt`**: `время уровень`. Уровень `N` значит, что волна накрывает линии от `0` до `N` (`2` накрывает все три, `0` только верхнюю). Допустимо от −5 до 5.

Некорректные записи пропускаются, номер записи и причина выводятся в консоль.

## Сборка из исходников

[Visual Studio 2026 Community](https://visualstudio.microsoft.com/) с компилятором C++17 и [SFML 2.5.1](https://www.sfml-dev.org/download/sfml/2.5.1/).

1. Укажите каталоги SFML в свойствах проекта: `Include` и `Lib`.
2. Подключите библиотеки: `sfml-graphics`, `sfml-window`, `sfml-audio`, `sfml-system` (в Debug с суффиксом `-d`).
3. Скопируйте DLL SFML (из папки `bin`) и `openal32.dll` рядом с `.exe`.
4. Спрайты, шрифт и файлы расписаний должны лежать в рабочей папке игры.

## Структура

```
main.cpp            точка входа
Game.h / .cpp       игровой цикл, загрузка ресурсов и расписаний, коллизии
Player.h / .cpp     игрок: движение, здоровье, регенерация
Spider.h / .cpp     паук
Wave.h / .cpp       волна: анимация, цвет, момент удара
SpawnSchedule.h     структуры записей расписания
```

## Известные ограничения

- Нет экрана Game Over, паузы, рестарта и подсчёта очков.
- При очень высокой скорости паука столкновение может не засчитаться.
- Записи расписания с одинаковым временем обрабатываются с задержкой в один кадр.
